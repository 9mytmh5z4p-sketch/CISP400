Slide_Catalog_Data_Dictionary.md

| Column | Description |
| --- | --- |
| Slide Number | A sequential number of the slide in the slide deck. |
| Topic | The topic from P400_inventory.csv. Typically there will be multiple slides that have the same topic> |
| Subject | This is a no-more than one sentence description of what the slide is about. It should not have the same name as the topic Nor should there be multiple instances of slides with the same subject. |
| Title | The title of the slide. Slides titled <no title> Do not have a title and are usually used for code demonstrations. |
| Category | A higher level organizational description of the slides' role within the slide deck. A standardized listing of terms for this column can be found in Dictionary_of_Terms.csv. |
| Notes | Some older versions list this column as filename. These are various notes about this particular slide. It can also include File names to various resources. |
